# 个人主页

打开 `dist/index.html` 即可使用，无需安装依赖或构建。CSS、JavaScript、插画和图标均已内嵌，支持离线查看。

## 自定义

- 搜索 `你的名字` 和 `YOUR NAME`，替换姓名与网站标识。
- 修改 `<title>`、页面描述、个人介绍及兴趣标签。
- 搜索 `hello@example.com`，将全部出现位置替换为你的邮箱，包括复制按钮脚本。
- 两个作品与三篇手记均为示例。卡片文案位于 HTML 中，详情位于脚本的 `details` 对象中。

## 已包含

响应式布局、手机菜单、浅色与深色主题、项目和手记详情弹窗、复制邮箱、键盘焦点、减弱动画偏好支持。

主题设置保存在当前浏览器中。联系按钮使用 `mailto:`，会打开系统配置的邮件应用。
